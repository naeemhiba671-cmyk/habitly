HABITLY — CODGEN FRONTEND INTERNSHIP, WEEK 1

FILES
- index.html
- css/style.css

HOW TO OPEN
1. Extract the ZIP file.
2. Open the habitly folder.
3. Double-click index.html. It should open in your browser.
4. Internet is only needed to load the Google Font (Inter); the page layout itself is local.

IMPORTANT
- This is a static HTML/CSS project, as required for Week 1.
- The Complete buttons are visual only; they do not change data.
- The date and habit/stat values are hard-coded sample content. Update them in index.html if needed.
- The design uses the brief's navy (#0B1F3A), teal (#14B8A6), background (#F8FAFC),
  Inter font, 12px card radius, CSS color/spacing variables, and the required footer wording.

RESPONSIVE CHECK
Use your browser's developer tools (F12) and device toolbar to check:
- 360px phone: one column
- 768px tablet: two habit columns
- 1280px laptop: three habit columns
